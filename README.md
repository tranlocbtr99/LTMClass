# LTMClass

Multi-tenant teaching management platform for independent tutors, students and guardians.

## Product scope
Teacher workspaces, class management, enrollment, schedules, attendance, materials, assignments, online exams, grades, guardian notifications and tuition records.

## Planned stack
React + Vite + TypeScript + Tailwind CSS (PWA); Hono on Cloudflare Workers; Cloudflare D1 and R2.
